Guia do Usuário - Calculadora de Custas

Bem-vindo! Este guia explica como utilizar todas as funcionalidades da calculadora para criar orçamentos precisos e rápidos.

Painel Principal (Abas)

A calculadora é dividida em abas, cada uma para um tipo específico de cálculo:

  • Valor Variável: Use para atos cujo valor depende de uma base de cálculo, como escrituras, registros e averbações com valor declarado.
  • Valor Fixo: Para atos com preço tabelado, como reconhecimento de firma, autenticações e procurações.
  • Inventário: Ferramenta completa para calcular os custos totais de um inventário, incluindo escritura, registros e ITCMD.
  • Manual: Permite adicionar qualquer item com valor livre ao orçamento, como honorários, despesas de diligência, etc.
  • INCRA: Uma ferramenta para consultar o valor de referência de imóveis rurais conforme a Tabela do INCRA, útil para definir a base de cálculo.
  • ITCMD Avulso: Para calcular apenas o valor do ITCMD sobre um bem, ideal para doações simples ou conferências.
Funções Detalhadas
1. Aba "Valor Variável"

Esta é a função mais utilizada. O fluxo é simples:

  1. Tipo de Ato: Selecione o ato desejado (ex: Escritura com valor, Registro com valor).
  2. Identificação (Opcional): Dê um nome ao ato para facilitar a identificação no orçamento (ex: "Lote 12", "Apto 101").
  3. Valor do Ato/Imóvel: Insira a base de cálculo. Lembre-se da regra do Art. 113 (explicada abaixo)!

Opções Adicionais:

  • É averbação de construção?: Se marcado, abre uma sub-ferramenta para calcular o valor da obra com base na área (m²) e no CUB/m², preenchendo o campo "Valor do Ato" automaticamente.
  • Natureza do Ato:
    • Ato Padrão: Calcula sobre o valor total.
    • Ato com Reserva de Usufruto: Divide o ato em dois: a venda da "nua-propriedade" (valor total) e a instituição do "usufruto" (1/3 do valor total), adicionando ambos ao orçamento.
    • Apenas o Usufruto: Calcula o ato usando apenas 1/3 do valor informado como base.
  • Adicionar ato correspondente: Se você calcula uma escritura, esta opção adiciona automaticamente o registro correspondente (e vice-versa), economizando tempo.
  • Adicionar ITCMD/ITBI: Calcula e adiciona os impostos de transmissão ao orçamento. O ITBI é fixo em 2% (em geral), e o ITCMD usa a alíquota progressiva do estado (2%, 3% ou 4%).
2. Aba "Inventário"

Esta aba automatiza o cálculo de inventários e partilhas. O sistema calcula a escritura (com base na soma de todos os bens) e os registros individuais de cada imóvel.

  • Calcular ITCMD: Se marcado, o sistema também calculará o imposto devido com base nos dados da sucessão que você informar (cônjuge, número de herdeiros).
  • Lógica do ITCMD no Inventário: A calculadora assume uma partilha igualitária entre os herdeiros descendentes. A meação do cônjuge (50% dos bens comuns) não gera imposto. A herança (outros 50% e bens particulares) é dividida entre os herdeiros, e o imposto é calculado individualmente sobre a cota de cada um. Atenção: Para partilhas complexas, use a aba "ITCMD Avulso".
3. Aba "INCRA"

Use esta ferramenta para obter uma avaliação oficial de um imóvel rural. Siga os passos, preenchendo Município, Nível, Tipologia, Coluna de Referência e Área (em hectares). O valor calculado pode ser usado como base de cálculo na aba "Valor Variável".

Gerenciando o Orçamento (Painel da Direita)
  • Detalhes (▼): Mostra a composição do valor do ato (emolumentos, fundos, selo).
  • Editar (Lápis): Permite alterar a descrição e a identificação de um item já lançado.
  • Remover (Lixeira): Exclui o item do orçamento.
  • Limpar: Apaga todos os itens do orçamento (pede confirmação).
  • Imprimir: Abre opções para gerar uma versão resumida ou detalhada do orçamento para impressão.
Entendendo a Base de Cálculo (Art. 113)

A escolha do valor a ser inserido no campo "Valor do Ato/Imóvel" é crucial e segue uma regra legal estrita. Conforme o Art. 113 das Diretrizes Gerais Extrajudiciais do TJRO, a base de cálculo para os emolumentos deve ser sempre o maior valor dentre as seguintes opções:

  • I - O valor do negócio declarado pelas partes (ex: o preço de venda no contrato).
  • II - O valor venal do imóvel para fins de IPTU (para imóveis urbanos).
  • III - O valor total da declaração do ITR (terra nua + benfeitorias) (para imóveis rurais).
  • IV - O valor de avaliação fiscal usado para o recolhimento do imposto de transmissão (ITBI ou ITCMD).

Na prática: Você deve verificar todos esses valores e inserir o maior deles na calculadora. A responsabilidade por informar a base de cálculo correta é do usuário.
